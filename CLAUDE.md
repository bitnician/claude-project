## Next.js 16.4 / React 19.3

Per `AGENTS.md` (imported above), check `node_modules/next/dist/docs/` (`01-app/` for App Router) before writing Next.js code. Notable settings in `next.config.ts`:

- `cacheComponents: true` and `partialPrefetching: true` are enabled — data fetching/caching semantics follow the Cache Components model, not the legacy `fetch` cache.
- Tailwind CSS v4 is wired through Turbopack via the `@tailwindcss/turbopack` loader (no `postcss.config`). Theme tokens are defined with `@theme inline` in `src/app/globals.css`.
- Route types are global helpers (e.g. `LayoutProps<"/">` in `src/app/layout.tsx`), generated into `.next/types`.

## Commands

Package manager is **pnpm** (10.x).

```bash
pnpm dev            # dev server (Turbopack)
pnpm build          # production build
pnpm lint           # ESLint (flat config, eslint-config-next core-web-vitals + typescript)
pnpm typecheck      # tsc --noEmit
pnpm db:generate    # generate SQL migrations into ./drizzle from src/db/schema.ts
pnpm db:migrate     # apply migrations
pnpm db:push        # push schema directly (prototyping only)
pnpm db:studio      # Drizzle Studio
pnpm auth:generate  # generate Better Auth tables into src/db/auth-schema.ts
```

There is no test framework configured yet.

## Setup

Copy `.env.example` to `.env.local` and set `DATABASE_URL` (Neon **pooled** connection string), `BETTER_AUTH_SECRET` (`openssl rand -base64 32`), `BETTER_AUTH_URL`, and `NEXT_PUBLIC_APP_URL`. `drizzle.config.ts` loads `.env.local` then `.env` via dotenv.

## Architecture

Stack: App Router + TypeScript (strict, `@/*` → `src/*`) + Tailwind v4 + Better Auth + Drizzle ORM on Neon Postgres.

- **Database** — `src/db/index.ts` exports a single `db` built with the Neon serverless **HTTP** driver (`drizzle-orm/neon-http`). It throws at import time if `DATABASE_URL` is missing. The HTTP driver does not support interactive transactions. `src/db/schema.ts` is the single schema entry point used by both Drizzle Kit and the app; every table module must be re-exported from it.
- **Auth** — `src/lib/auth.ts` is the Better Auth server instance using the Drizzle adapter (`provider: "pg"`) with the full `schema` object. `nextCookies()` must stay the **last** plugin so Server Actions can set cookies. It's mounted at `src/app/api/auth/[...all]/route.ts` via `toNextJsHandler`. Client-side code uses `authClient` from `src/lib/auth-client.ts` (`better-auth/react`).
- **Auth tables are not yet created.** To add them: run `pnpm auth:generate`, add `export * from "./auth-schema";` to `src/db/schema.ts`, then `pnpm db:generate && pnpm db:migrate`. Re-run `auth:generate` whenever Better Auth plugins/config change the required schema.
